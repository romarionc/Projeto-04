## 📄 Sobre o Projeto

Esta etapa final consolida o projeto, focando na transição para produção. Centra-se em práticas profissionais, implementando controle de versão com Git/GitHub e versionamento semântico. Garantimos acessibilidade (WCAG 2.1 AA) com navegação por teclado e alto contraste. Por fim, aplicamos otimizações como minificação e compressão.

## ✨ Funcionalidades Principais

* **Estrutura Semântica:** Website construído com HTML5 semântico e validado pelo W3C.
* **Design System:** Interface consistente com CSS Custom Variables (cores, tipografia, espaçamento).
* **Layouts Responsivos:** Design mobile-first com 5 breakpoints, usando CSS Grid (12 colunas) e Flexbox.
* **Componentes de UI:** Cards, botões com estados (`:hover`, `:active`), modais, toasts e badges.
* **Navegação Interativa:** Menu principal com dropdown e menu mobile (hambúrguer).
* **Formulários Avançados:** Formulário de cadastro com validação nativa e máscaras de input (CPF, Telefone, CEP).
* **Interatividade (JS):** Sistema de SPA (Single Page Application) básico, templates JS e verificação de consistência de dados.
* **Acessibilidade (Nível AA):**
    * Navegação completa por teclado.
    * Contraste de cores 4.5:1.
    * Suporte a leitores de tela.
    * Modo escuro e modo de alto contraste.
* **Otimização de Performance:**
    * Minificação de arquivos CSS, JavaScript e HTML.
    * Compressão e otimização de imagens.
* **Versionamento Profissional:**
    * Controle de versão com Git.
    * Estratégia de branching (GitFlow).
    * Histórico de commits semânticos.
    * Sistema de releases com versionamento semântico (SemVer).

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação semântica.
* **CSS3:** Flexbox, Grid Layout, Custom Variables, Media Queries.
* **JavaScript (ES6+):** Manipulação do DOM, eventos e modularização.
* **Git & GitHub:** Controle de versão e gerenciamento do repositório.
* **W3C Validator:** Garantia de qualidade do HTML.
* **WCAG 2.1:** Diretrizes de acessibilidade.

## 🏁 Etapas do Projeto

Este projeto foi dividido em quatro entregas principais:

### 1. Entrega 01: Fundamentos e Estrutura (HTML)
* **Objetivo:** Criar a base estrutural sólida da plataforma com HTML5.
* **Entregáveis:**
    * Mínimo de 3 páginas HTML (`index.html`, `projetos.html`, `cadastro.html`).
    * Estrutura semântica completa e hierarquia de títulos lógica.
    * Formulário complexo com tipos de input HTML5, validação nativa e máscaras.
    * Estrutura de pastas organizada e arquivos validados no W3C.

### 2. Entrega 02: Design System e Responsividade (CSS)
* **Objetivo:** Aplicar conceitos modernos de CSS, sistemas de design e responsividade.
* **Entregáveis:**
    * Design system com variáveis CSS (paleta de 8 cores, 5 tamanhos de fonte).
    * Layouts responsivos com CSS Grid (estrutura geral) e Flexbox (alinhamentos).
    * Mínimo de 5 breakpoints bem definidos.
    * Componentes de interface (cards, botões com estados, menu mobile, modals, etc.).
    * Estrutura de CSS modular e organizada.

### 3. Entrega 03: Interatividade (JavaScript)
* **Objetivo:** Transformar a interface estática em uma aplicação web dinâmica.
* **Entregáveis:**
    * Implementação de um sistema de SPA (Single Page Application) básico.
    * Criação de sistema de templates JavaScript.
    * Funcionalidade de verificação de consistência de dados em formulários.
    * Código JavaScript modular e organizado por funcionalidade.

### 4. Entrega 04: Produção e Práticas Profissionais
* **Objetivo:** Consolidar o projeto com práticas de versionamento, acessibilidade e otimização.
* **Entregáveis:**
    * Repositório GitHub completo com estratégia GitFlow, commits semânticos e releases.
    * Implementação total de acessibilidade (WCAG 2.1 Nível AA).
    * Otimização de performance (minificação de arquivos e compressão de imagens).
    * Documentação técnica completa (este README).
